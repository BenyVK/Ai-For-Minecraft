# 🤖 Ai For Minecraft

یک پلاگین سبک برای **Paper** که به بازیکن‌ها اجازه می‌دهد داخل ماینکرفت مستقیم با هوش مصنوعی صحبت کنند. این پلاگین با هر API سازگار با **OpenAI**

🌐 **English version:** [README.md](https://github.com/BenyVK/Ai-For-Minecraft/blob/main/README.md)

---

## ✨ امکانات

- 💬 پرسیدن سوال با دستور `/ai <سوال>`
- 🔒 **مکالمه‌ی خصوصی**: فقط خود بازیکن سوال و جواب را می‌بیند
- 🧠 **حافظه‌ی مکالمه** برای هر بازیکن (هوش مصنوعی پیام‌های اخیر را یادش می‌ماند)
- 💾 چت هر بازیکن در فایلی به اسم همان بازیکن ذخیره می‌شود
- 🗑️ بازیکن‌ها می‌توانند تاریخچه‌ی خودشان را با `/ai history delete` پاک کنند
- 📝 فایل اختیاری `log.log` که همه‌ی کارهای پلاگین را ثبت می‌کند
- ⌨️ حالت اختیاری چت: بدون اسلش و فقط با نوشتن `ai سلام` در چت (پیام خصوصی می‌ماند)
- ⏱️ کول‌داون بین درخواست‌ها و محدودیت طول جواب
- ⚡ همه‌ی کارهای شبکه و فایل **غیرهمزمان** است، پس سرور لَگ نمی‌کند

## 📥 نصب

1. فایل `.jar` پلاگین را دانلود کنید (یا [خودتان بیلد کنید](#-ساخت-از-سورس)).
2. آن را داخل پوشه‌ی `plugins` سرور بیندازید.
3. سرور را یک بار روشن کنید. پلاگین فایل `plugins/ai-server/configvk.yml` را می‌سازد.
4. سرور را خاموش کنید، فایل `configvk.yml` را باز کنید و `api-key` را وارد کنید.
5. سرور را دوباره روشن کنید و داخل بازی `/ai سلام` را بزنید.

## 🎮 دستورات

| دستور | توضیح |
|---|---|
| `/ai <سوال>` | پرسیدن سوال از هوش مصنوعی |
| `/ai history` | نمایش تعداد پیام‌های ذخیره‌شده‌ی شما |
| `/ai history delete` | پاک کردن تاریخچه‌ی چت و حافظه‌ی هوش مصنوعی از شما |

**پرمیژن:** `aiserver.use` (به صورت پیش‌فرض برای همه فعال است)

## ⚙️ تنظیمات

فایل: `plugins/ai-server/configvk.yml`

| کلید | پیش‌فرض | توضیح |
|---|---|---|
| `base-url` | `https://.......` | آدرس پایه‌ی API سازگار با OpenAI |
| `api-key` | `PUT_YOUR_API_KEY_HERE` | کلید API شما |
| `model` | `MODEL_AI` | اسم مدل |
| `temperature` | `0.7` | میزان خلاقیت جواب‌ها |
| `max-tokens` | `400` | حداکثر طول هر جواب (بر حسب توکن) |
| `max-reply-chars` | `1000` | جواب‌های بلندتر از این بریده می‌شوند |
| `system-prompt` | *(داخل فایل ببینید)* | دستوری که رفتار هوش مصنوعی را مشخص می‌کند |
| `history-size` | `10` | تعداد پیام‌های اخیری که به عنوان زمینه برای هوش مصنوعی فرستاده می‌شود |
| `max-saved-messages` | `200` | تعداد پیام‌هایی که در فایل هر بازیکن نگه داشته می‌شود |
| `cooldown-seconds` | `5` | فاصله‌ی بین دو درخواست یک بازیکن |
| `log` | `true` | اگر `true` باشد `log.log` نوشته می‌شود |
| `chat.enabled` | `false` | فعال کردن حالت چت (بدون نیاز به اسلش) |
| `chat.prefix` | `ai ` | پیام‌هایی که با این پیشوند شروع شوند به هوش مصنوعی می‌روند |

> ⚠️ بعد از تغییر `configvk.yml` باید **سرور را ریستارت** کنید.

## 📁 فایل‌هایی که پلاگین می‌سازد

```
plugins/ai-server/
├── configvk.yml          ← تنظیمات
├── log.log               ← لاگ فعالیت‌ها (فقط اگر log: true باشد)
└── chats/
    ├── Steve.json        ← چت ذخیره‌شده‌ی بازیکن "Steve"
    └── Alex.json
```

هر فایل چت یک لیست JSON است. هر آیتم یک `role` (مقدار `user` یا `assistant`)، متن پیام در `content` و زمان در `time` دارد.

### درباره‌ی لاگ

وقتی `log: true` باشد، فایل `log.log` این موارد را ثبت می‌کند: روشن و خاموش شدن پلاگین، اینکه چه کسی چه چیزی پرسیده، جواب‌های هوش مصنوعی (کوتاه‌شده تا ۲۰۰ کاراکتر)، پاک شدن تاریخچه‌ها و همه‌ی خطاها. چون سوال‌های بازیکن‌ها داخل آن است، بهتر است به بازیکن‌ها اطلاع بدهید یا آن را خاموش کنید. **کلید API هرگز داخل لاگ نوشته نمی‌شود.**

## 🔨 ساخت از سورس

پیش‌نیاز: JDK 21 یا بالاتر.

```bash
git clone https://github.com/BenyVK/Ai-For-Minecraft.git
cd Ai-For-Minecraft
./gradlew build
```

فایل jar داخل `build/libs/` ساخته می‌شود. (در ویندوز از `gradlew.bat build` استفاده کنید.)

پلاگین با `options.release = 21` کامپایل می‌شود، پس حتی اگر با JDK جدیدتر بیلدش کنید روی سرورهایی که جاوای 21 یا بالاتر دارند اجرا می‌شود.

## 🛠️ رفع مشکل

| مشکل | راه حل |
|---|---|
| `The API key is not set in configvk.yml.` | کلید واقعی را در `api-key` بگذارید و سرور را ریستارت کنید |
| `Error communicating with the AI (code 401)` | کلید API اشتباه یا منقضی شده است |
| `Error communicating with the AI (code 404)` | `base-url` و `model` را بررسی کنید |
| خطای `UnsupportedClassVersionError` در کنسول | سرور را با جاوای 21 یا بالاتر اجرا کنید |
| خطای `ClassNotFoundException` موقع شروع | خط `main:` در `plugin.yml` باید با پکیج `AiServer.java` یکی باشد |
| نه جواب می‌آید نه خطا | `log: true` بگذارید و فایل `plugins/ai-server/log.log` را بخوانید |

## 🔐 نکات امنیتی

- کلید API خودتان را هرگز به اشتراک نگذارید و فایل `configvk.yml` را با کلید داخلش روی گیت‌هاب آپلود نکنید.
- اگر کلیدی را اشتباهی به اشتراک گذاشتید، آن را از پنل سرویس‌دهنده حذف کنید و یک کلید جدید بسازید.
